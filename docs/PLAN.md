# Black Hole Graph — план реализации

Плагин для Obsidian: реалистичная чёрная дыра (рейтрейсинг гравитационного линзирования
+ аккреционный диск), вокруг неё по орбитам летают заметки из хранилища, заметки соединены
линиями по wiki-ссылкам.

---

## 0. v2: папки — это планеты

Вторая итерация поменяла модель сцены:

- **Папка = планета.** Каждая папка хранилища становится планетой на орбите вокруг дыры
  (радиус `13…30 r_s`, кеплеровская скорость, наклон плоскости ±8°).
- **Заметка = спутник.** Заметки летают вокруг своей планеты (`2.0…3.6` радиуса планеты,
  наклон орбит ±35°), а не вокруг дыры.
- **Два режима камеры.** Системный вид: видны дыра, планеты и подписи папок, заметки — точками.
  Фокус на планете: планета крупно, её заметки — читаемыми карточками.
- **Навигация.** Клик по планете — подлёт к ней; клик по пустому месту или `Esc` — назад
  в систему; клик по тени — крупный план самой дыры.
- **Связи.** Внутри планеты — дуги между заметками; между планетами — агрегированные
  серые пунктирные лучи, по одному на пару планет.
- **Фон.** Чёрный, без туманностей. Далёкие галактики — ASCII-глифы, нарисованные в 2D
  (резкие на любом масштабе), со слабым линзированием их экранного положения.

## 1. Что видит пользователь

- Отдельная вкладка (`ItemView`) с чёрной дырой почти на весь экран.
- Чёрная дыра — не картинка, а шейдер: тень, фотонное кольцо, аккреционный диск,
  линзированный фон (звёзды «загибаются» над и под дырой), эффект Доплера и гравитационное
  красное смещение. Камера медленно плывёт, есть параллакс от мыши.
- Заметки — карточки с заголовком (и опционально первым абзацем), летают по орбитам в
  плоскости диска с наклоном; внутренние быстрее (кеплеровское вращение ∝ r^-1.5).
- Связи — кривые Безье между карточками, подсвечиваются при наведении, уходящие «за»
  дыру тускнеют.
- Взаимодействие: hover → подсветка узла и его связей; клик → открыть заметку;
  drag → вращение камеры; колесо → зум (с ограничением, чтобы не воевать со скроллом);
  cmd/ctrl+клик → открыть в новой вкладке.

## 2. Архитектура: два слоя

```
┌──────────────────────────────────────────────┐
│  #bh-notes  (2D canvas, overlay)             │  карточки заметок + связи + hover
├──────────────────────────────────────────────┤
│  #bh-canvas (WebGL2)                         │  чёрная дыра, диск, звёзды, bloom
└──────────────────────────────────────────────┘
```

Почему два слоя, а не всё в WebGL:

| | WebGL-спрайты заметок | 2D-canvas overlay |
|---|---|---|
| Читаемость текста | нужны текстуры, пересборка при правке | `fillText`, всегда чётко |
| 300 узлов + 800 связей | дорого | дёшево |
| Хит-тест, hover | вручную | тривиально |
| Линзирование заметок | да | нет |

Заметки — это UI, их линзить не нужно (и вредно: текст поедет). Чёрная дыра — физика.
Компромисс: заметки **окклюдируются** тенью дыры (если заметка за дырой и её экранная
проекция попадает в круг тени — не рисуем; на краю — плавное затухание) и получают
глубинные подсказки (масштаб, яркость, размытие по z).

## 3. Рендер чёрной дыры (главная часть)

### 3.1 Физика

Метрика Шварцшильда, геометрические единицы `G = c = 1`, масса `M`, `r_s = 2M`.

- Горизонт: `r = 2M`
- Фотонная сфера: `r = 3M = 1.5 r_s`
- Видимый радиус тени: `b_crit = 3√3 M ≈ 2.598 r_s`
- Уравнение фотонной геодезической в плоскости луча, `u = 1/r`:

```
u'' + u = 3 M u²          (штрих — по φ)
```

- Слабое поле: `α ≈ 4M/b`
- Диск (Шакура–Суньяев): `T ∝ r^(-3/4)`, внутренний край `r_ISCO = 6M = 3 r_s`
- Кеплерова скорость: `Ω = √(M/r³)`, `v = Ω r`
- Доплер: `δ = 1 / (γ (1 − β·n̂))`, `I_obs = δ⁴ I_emit`
- Гравитационное красное смещение: множитель `√(1 − r_s/r)`

### 3.2 Алгоритм трассировки (на пиксель)

1. Луч: `ro = camPos`, `rd` из обратной проекции пикселя.
2. Плоскость фотона: `n = normalize(cross(ro, rd))`, базис `e1 = normalize(ro)`,
   `e2 = cross(n, e1)`. Если `ro ∥ rd` — радиальный случай, обрабатываем отдельно.
3. Начальные условия: `r0 = |ro|`, `u0 = 1/r0`,
   `du/dφ = −u0 · (v_r / v_φ)`, где `v_r = dot(rd, e1)`, `v_φ = dot(rd, e2)`.
4. Интегрируем `u'' = −u + 3 M u²` (RK4 или полунеявная схема), шаг адаптивный
   (`dφ ≈ 0.01…0.03` ближе к фотонной сфере, крупнее вдали), 60…200 шагов.
5. На каждом шаге восстанавливаем 3D-точку: `p = (1/u) · (cos φ · e1 + sin φ · e2)`.
6. Остановки:
   - `u > 1/r_s` → луч проглочен (пиксель чёрный, кроме накопленного диска);
   - `r > r_escape` → сэмплим небо по финальному направлению;
   - пересечение плоскости диска (`p.y` меняет знак) при `r ∈ [r_ISCO, r_out]` →
     добавляем излучение с альфа-блендингом (front-to-back).
7. Цвет диска: чернотельная LUT по `T_obs = T(r) · δ · √(1 − r_s/r)`, яркость `· δ⁴`,
   шум (fBm) в координатах `(r, φ − Ω(r)·t)` → дифференциальное вращение и волокна.
8. Пост: bloom (3 мипа), ACES tonemap, лёгкий dithering.

Ключевой момент, за который платим: диск рисуется на **пересечениях трассируемого луча**,
поэтому автоматически получаются:
- вторичное изображение «над» дырой (свет от дальней стороны диска, обогнувший дыру);
- видимая нижняя сторона диска за дырой;
- корректное искривление фона и фотонное кольцо.

Именно это даёт вид «Гаргантюа» из «Интерстеллара», а не дешёвый радиальный градиент.

### 3.3 Небо

Двумя слоями:

1. **Текстура** 1024×512 (equirect, генерируется один раз на GPU шейдером
   `sky.frag.glsl`): холодный градиент глубокого космоса, цветные туманности
   (fbm + ridged-шум для волокон), полоса Млечного Пути с пылевыми прожилками,
   гранулярная дымка и слабое ядро в направлении галактического центра.
2. **Звёзды — процедурные**, три слоя с разной плотностью. Причина: в текстуре
   звёзды расплываются, а рисование точкой даёт резкость при любом разрешении
   рендера. Радиус звезды ограничен долей ячейки (0.26), иначе в плотных слоях
   ячейка целиком засвечивается и небо превращается в решётку из квадратов.
   Яркость держится ниже порога bloom, чтобы звёзды не раздувались блочными
   ореолами на ¼ разрешения.

Сэмплируется по финальному (искривлённому) направлению луча. Яркие звёзды,
проходящие рядом с фотонной сферой, растягиваются в дуги Эйнштейна — это
следствие линзирования, а не эффект.

### 3.3.1 Доплер

`I_obs = I_emit · shift^p`, где `shift = δ · √(1−r_s/r)`, а показатель `p`
плавно спадает от 3.2 у горизонта до 0.6 на периферии
(`smoothstep(9, 4, r)`). Полный `δ⁴` физически верен, но на внешнем диске
читается как «кривой фонарь»: одна сторона пересвечена, другая почти чёрная.
Цветовая температура (`T_obs = T · shift`) остаётся физической везде — она и
даёт синеватое приближающееся и красноватое удаляющееся плечо.

### 3.4 Fallback-режим «Fast»

Если WebGL2 недоступен / мобилка / пользователь выбрал: радиальное линзирование
пререндеренного неба + экранные эллиптические дуги диска (без вторичного изображения).
Дешево, всё ещё симпатично.

### 3.5 Эскиз шейдера

```glsl
vec3 trace(vec3 ro, vec3 rd) {
  vec3 n  = normalize(cross(ro, rd));
  vec3 e1 = normalize(ro);
  vec3 e2 = cross(n, e1);
  float r0 = length(ro);
  float u  = 1.0 / r0;
  float du = -u * dot(rd, e1) / max(dot(rd, e2), 1e-4);
  float phi = 0.0;
  vec3  col = vec3(0.0);
  float trans = 1.0;

  for (int i = 0; i < MAX_STEPS; i++) {
    float dphi = stepSize(u);
    // RK4 для (u, du)
    vec3 pPrev = pos(u, phi, e1, e2);
    phi += dphi;  integrate(u, du, dphi);
    vec3 p = pos(u, phi, e1, e2);
    if (u > 1.0 / RS) return col;                       // горизонт
    if (1.0/u > R_ESCAPE) { col += trans * sky(dir(p)); break; }
    if (pPrev.y * p.y < 0.0) {                          // пересечение диска
      float t = pPrev.y / (pPrev.y - p.y);
      vec3 hit = mix(pPrev, p, t);
      float rr = length(hit.xz);
      if (rr > R_IN && rr < R_OUT)
        col += trans * diskEmission(rr, atan(hit.z, hit.x), rd);
    }
  }
  return col;
}
```

## 4. Слой заметок

### 4.1 Данные

- `app.vault.getMarkdownFiles()` + `metadataCache.resolvedLinks` → неориентированный граф.
- Вес узла = in + out degree.
- Кластеризация по папке (или по тегу) → раскладываем кластеры по секторам/кольцам,
  чтобы соседние по смыслу заметки летали рядом.
- События `vault` / `metadataCache.resolved` / `rename` / `delete` → debounce 500 мс → перестройка.
- Фильтры: исключить папки/теги, «только связанные», лимит узлов (топ-N по весу +
  опционально текущая папка).

### 4.2 Орбитальная модель

Никакого n-body (нестабильно и непредсказуемо). Параметризованные орбиты:

```
note.r      ∈ [1.6 r_shadow … 8 r_shadow]   // радиус кольца
note.incl   ∈ [−12° … +12°]                 // наклон орбитальной плоскости
note.phase0 ∈ [0, 2π)
note.ω      = k / r^1.5                     // кеплеровское, внутренние быстрее
pos         = R(incl) · (r cos(θ), 0, r sin(θ)),  θ = phase0 + ω·t
```

Плюс мелкое вертикальное покачивание и очень медленная прецессия, чтобы не выглядело
жёсткой каруселью. Позиции сохраняются в `data.json` по пути заметки — пользователь может
перетащить карточку на другое кольцо.

### 4.3 Отрисовка (2D canvas)

- Проекция через ту же камеру, что и в WebGL (общий `Camera` модуль).
- Сортировка по глубине, back-to-front.
- Карточка: скруглённый прямоугольник, полупрозрачная подложка, название.
  Дальние — меньше, тусклее, с лёгким блюром (эмулируем через alpha/desaturate, `filter: blur` дорого).
- Связи: не прямые линии, а **дуги по орбите**. Радиус и высота интерполируются
  между заметками, азимут проходит короткий путь вокруг дыры (до 26 сегментов),
  каждая точка проецируется камерой. Поэтому связь огибает чёрную дыру, а не
  режет кадр по диагонали. При hover — усиленное свечение линии.
- Окклюзия тенью дыры: если `z_note < z_bh` и экранное расстояние до центра `< shadowRadius`
  → не рисуем (с мягким краем).
- Текст: `ctx.font`, `devicePixelRatio`, обрезка по ширине, ellipsis.

### 4.4 Взаимодействие

- Хит-тест по прямоугольникам в экранных координатах (обратный порядок сортировки).
- Клик → `workspace.getLeaf(modKey ? 'tab' : false).openFile(file)`.
- Drag камеры (с инерцией), wheel-зум, `Escape` — сброс камеры.
- Hover-карточка крупнее + превью первой строки (одна DOM-подсказка, не 300).

## 7. Этапы

**M0 — каркас (≈1–2 ч).** Манифест, сборка, `ItemView` с двумя канвасами, ribbon + команда,
настройки-заглушка. Открывается пустая вкладка.

**M1 — граф без дыры (≈3–4 ч).** `VaultGraph`, орбитальная раскладка, 2D-слой заметок и
связей, hover/клик/камера. Уже полезно и отлаживаемо.

**M2 — дыра на WebGL2 (≈8–12 ч).** Трассировка геодезических, диск, небо, bloom, tonemap.
Здесь основная тонкая настройка (яркость, температура, шаги).

**M3 — интеграция (≈3–4 ч).** Окклюзия заметок тенью, глубинные подсказки, синхронизация
камеры, Fast-режим, ресайз/DPR/context-lost.

**M4 — полировка (≈3–4 ч).** Настройки (качество, температура диска, наклон камеры,
фильтры заметок), мобильный профиль, сохранение раскладки, README.

## 8. Риски и решения

| Риск | Решение |
|---|---|
| Шейдер тяжёл на встроенной графике | FBO 0.5×, лимит шагов, Fast-режим по умолчанию на `Platform.isMobile` |
| Тексты заметок не линзятся | осознанный выбор: заметки = UI; окклюзия + глубина дают ощущение объёма |
| 5000 заметок → каша | топ-N по весу, фильтры, «фокус на папке», лимит связей |
| Конфликт со скроллом/хоткеями | зум только с `ctrl`/`wheel` внутри вкладки, отдельный view |
| Тема «сломает» фон | фон дыры самодостаточен, вкладка непрозрачная; фон под всем воркспейсом — отдельная экспериментальная опция позже |
| WebGL context loss | обработчик `webglcontextlost` → пересоздание ресурсов |

## 9. Анимация и события

Что двигается уже сейчас:

| Что | Как |
|---|---|
| Аккреционный диск | дифференциальное вращение `Ω ∝ r^-1.5` через сдвиг шумовых координат |
| Горячие пятна | два сгустка на разных радиусах (`cos²⁶(φ − ωt)`), дают заметное движение даже там, где турбулентность слабая |
| Турбулентность | медленная эволюция домена шума (`q.z += t·0.02`) |
| Звёзды | мерцание `0.8 + 0.2·sin(1.9t + phase)` |
| Камера | медленный авто-дрейф через 4 с после последнего взаимодействия (~150 с на оборот) |

### Бэклог: редкие события

Схема: модуль `scene/EventDirector.ts` с расписанием (Пуассон, среднее 1 событие
в 4–8 минут) и списком сценариев; каждый сценарий — функция `(t01) => uniforms`
(0…1 — прогресс), которую шейдер и слой заметок читают.

- **Вспышка** — `diskBrightness` × 2.5 на 6 с с быстрым фронтом и медленным спадом,
  плюс ударная волна в шуме (кольцо, расходящееся по диску).
- **Коллапс** — на 20 с: диск схлопывается к ISCO, камера подъезжает, bloom растёт,
  затем медленное восстановление; сбрасывает накопленный «магнетизм».
- **Приливный выброс** — узкий джет по оси +Y, видимый только из-за линзирования
  его задней части.
- **Падение заметки** — выбранная заметка (по индексу) спирально уходит к горизонту,
  растягивается и краснеет, затем возвращается на орбиту. Чисто визуально, файл не трогаем.
- **Гравитационная волна** — короткое (1.5 с) дрожание камеры + линзирование
  фона искажается синусом.

Все эффекты должны быть аддитивными к базовому рендеру и выключаться настройкой
`Enable events`.
