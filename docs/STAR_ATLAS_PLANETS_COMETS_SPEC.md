# ТЗ v3: procedural star atlas, textured planets and orbital links

## A. Удалить старые слои

Полностью отключить и не рисовать одновременно:

- текущий процедурный `starField()` из основного black-hole shader;
- текущие ASCII-галактики и foreground star layer из `AsciiSky`;
- старый плоский halo, если он визуально заменяет тонкое photon ring.

Должен остаться один управляемый источник фонового неба: `StarAtlas`.

## B. Процедурная текстура неба

Создать `StarAtlas` как equirectangular RGBA texture с alpha:

- Ultra: 8192×4096, RGBA8, без mipmap или с контролируемым mipmap;
- High: 4096×2048;
- Fast: 2048×1024;
- генерация один раз при загрузке/смене качества, не каждый кадр;
- texture sampling по направлению последнего луча.

Alpha:

- `alpha = 0` в чистом космическом фоне;
- звёзды и цветовые облака имеют мягкую alpha;
- composite выполняется поверх чёрного, цвет фона никогда не становится серым.

Цвет:

- горячая внутренняя зона: синий/циан;
- средняя зона: белая;
- внешняя зона: красная/оранжевая;
- распределение не должно выглядеть как плоский радиальный градиент.

Звёзды:

- hash/seed deterministic;
- разные спектральные классы через blackbody RGB;
- редкие крупные звёзды, большинство — 1 пиксель;
- мягкий alpha только у bright stars;
- не использовать quarter-resolution bloom для всего atlas;
- Atlas не должен быть мыльным при renderScale=1.

Линзирование:

- для лучей, которые выходят за пределы photon sphere, sample atlas по bent direction;
- звёзды позади чёрной дыры должны изгибаться в arc/Eintein-ring формы;
- в области shadow atlas должен быть полностью скрыт;
- гравитационный redshift применять к яркости/температуре звёзд около `r_ph`;
- не рисовать фальшивое толстое кольцо поверх физического результата.

## C. Photon ring

Сохранить физический тонкий photon ring из геодезической трассировки:

- геометрия `u'' + u = 3Mu²` не меняется;
- ring формируется накоплением лучей около `b_crit = 2.598076`;
- визуальная ширина — 1–3 пикселя в native render;
- bloom не должен размывать его больше чем на 2–4 пикселя;
- запрещено рисовать широкую самостоятельную окружность вместо трассировки.

## D. Планеты

Для каждой планеты использовать процедурные материалы:

- diffuse albedo из deterministic noise/fBm;
- normal-map из градиента noise:
  `normal = normalize(vec3(-dHeightDx * strength, 1, -dHeightDz * strength))`;
- смешать крупные континенты/пятна, мелкий рельеф и цветовые зоны;
- directional light от accretion disk/black hole;
- ambient почти чёрный;
- тонкий atmospheric rim по Fresnel:
  `rim = pow(1 - dot(normal, viewDir), 3..5)`;
- цвет halo зависит от seed планеты: cyan, blue, violet, amber;
- diffuse, normal и atmosphere должны быть процедурными и не требовать внешних image assets.

## E. Орбиты

Видимые орбиты:

- орбитальный путь каждой планеты вокруг black hole — тонкая холодная линия, alpha 0.18–0.35;
- орбиты спутников вокруг планеты — ещё тоньше, alpha 0.12–0.25;
- depth/occlusion корректны: дальняя часть орбиты темнее, участки за black hole скрываются;
- system view: планетарные орбиты видны всегда;
- focus view: орбита выбранной планеты и орбиты её спутников становятся ярче;
- не превращать орбиты в толстые кольца.

## F. Красные кометы-связи

Вместо постоянных длинных линий между заметками:

- связь остаётся тонкой серой пунктирной направляющей с низкой alpha;
- по каждой связи движется маленькая красная комета;
- комета состоит из яркой головы 2–4 px и хвоста 8–24 px;
- скорость 0.12–0.30 пути/сек, deterministic phase из hash(source+target);
- голова красно-оранжевая, хвост с alpha fade;
- при hover заметки комета становится ярче и крупнее;
- для inter-planet links комета летит по дуге между планетами;
- cap: максимум 96 активных comet instances в system view и 160 в focus view;
- не использовать тяжёлый particle system и не аллоцировать объекты в кадре.

## G. Acceptance

- после старта отсутствуют старые ASCII-звёзды и старый procedural starField;
- atlas выбирается по quality и создаётся один раз;
- чистый фон остаётся RGB 0/alpha 0 до atlas composite;
- photon ring тонкий и физический;
- planet materials показывают рельеф при вращении камеры;
- atmospheric rim виден только по краю планеты;
- орбиты видны, но не закрывают чёрную дыру;
- comet heads движутся по связанным путям;
- `npm run build`, `npm run smoke` без ошибок;
- browser console без shader compile errors.
